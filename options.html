Nudge settings

Reads your Todoist, shows the next step on every new tab, and pings you when a project goes quiet.

Todoist

In Todoist: Settings, Integrations, Developer, copy the API token. It stays in this browser.

Projects to watch

These show on the new tab and get stale nudges. Sections count as projects, so "Garden" inside "Big Projects" is its own row.

Connect Todoist to see your projects.

When to nudge

Notifications

Break-end reminders always come. Switched-off notifications still show on the new tab.

Weather

Shown next to the date: now and tomorrow, from Open-Meteo (free, no account). Leave it empty to hide the weather.

Your day

so late-night work still counts as the same day

New tab

Show or hide parts of the new tab. Changes show on the next new tab.

Pause list

Opening these shows your next step first, three hand-picked sites worth your time instead, and the option to start a timed break. One site per line. Subdomains are included, so reddit.com also covers old.reddit.com.

Hand-picked sites

Your thumbs. Liked sites show up more often; hidden ones never do. Click a hidden one to bring it back.

No ratings yet. Use the thumbs under any link.

Claude wording (optional)

Uses a Claude API key from console.anthropic.com. API usage is billed separately from a Claude Pro subscription. With Haiku 5.5 a nudge costs a small fraction of a cent. Without a key, nudges use built-in wording.

Backup

One file with your settings, shortcuts, note, weather place and site ratings. Use it for a new PC or to share a setup. Your Todoist token and API key are left out.
